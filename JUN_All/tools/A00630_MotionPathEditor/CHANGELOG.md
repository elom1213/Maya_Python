## v01.12 (2026-11-20)

- **[New] Speed 탭에도 `Edit Path`** (계획서 G4) — Path 탭 버튼과 **같은 편집 툴 하나**를 켜고 끈다(두 버튼은 늘 같은 상태, 켜짐 = 연한 빨강).
  뷰포트에서 점 · 폴오프 · 매니퓰레이터로 끄는 동안 **Speed 그래프가 라이브로 따라 바뀐다**(회색 = 원래, 색 = 새).
- **[New] 그래프의 폴오프 [a, b] 색 띠** — Edit Path 에서 고른 점의 폴오프 범위를 프레임마다 **뷰포트와 같은 가중치 색**(노랑 1 → 빨강 0)으로, 고른 프레임은 세로선.
- **[New] Frames > `Falloff`** — 그 [a, b] 와 앞뒤로 반경만큼만 그래프로(고른 것이 없으면 Whole Path).
- **[New] 폴오프 범위 위치 스무딩** — 고른 점이 있으면 **Smooth Range = 그 폴오프 범위만, 가중치만큼** 경로 위치를 부드럽게(브러시 Smooth Shape 또는 Smooth Acceleration 결과를 w 로 섞음).
  범위 밖은 정확히 그대로, undo 한 번. 브러시가 Smooth Speed(타이밍)면 Smooth Shape 로 대신하고 로그로 알린다. 고른 것이 없으면 예전처럼 보이는 구간 전체.
- **[Change] 매니퓰레이터 굵기 1.5 배**(선 2 → 3 px, 잡은 부분 3 → 4.5 px, 화살표 머리도) — 사용자 요청. 플러그인 1.9.
- 시험 `test_speed_falloff.py` 19항목(두 버튼 · 띠 · Frames Falloff · 라이브 · 폴오프 Smooth: 범위 밖 그대로 · 가속도 48% 감소 · undo 한 번 · Speed 브러시 대신 Shape · 선택 없으면 예전). 전체 484/484.

## v01.11 (2026-11-20)

- **[New] 이동 · 회전 매니퓰레이터** (계획서 G3). Edit Path 가 켜져 있고 고른 점이 있으면 그 **무게중심**에 기즈모가 나온다(화면 크기 고정, 메시에 안 가림).
  - **Move**: 축 화살표(X 빨강 · Y 초록 · Z 파랑) = 그 축으로만, 평면 사각형 = 그 평면에서, **가운데 사각형 = 점을 그냥 끄는 것과 같다(Drag in 을 따른다)**.
  - **Rotate**: 축 고리 = 그 축 둘레, 바깥 고리 = 화면 시선 둘레. 피벗 = 고른 점들의 가운데. 끄는 동안 커서 옆에 `+22.5 deg`.
  - 고른 점 = 1, 폴오프 범위는 가중치만큼(회전은 **각도 x 가중치**) — 폴오프를 켜고 회전하면 경로가 부드럽게 휜다.
  - 창 Edit 의 **Manipulator** 줄: `Move / Rotate` · `Axes World / Path`(Path = 고른 점 자리의 경로 방향 · 위 · 옆). **뷰포트 `w` / `e`** 로도 바꾼다(편집 툴일 때만 툴이 받는다 — 마야 Move/Rotate 툴로 안 나간다).
  - 기즈모가 점보다 먼저 잡힌다. **Shift / Ctrl 클릭은 늘 점 선택**. 오른쪽 버튼 = 취소. 놓으면 Ctrl+Z 한 번.
  - 키만 고르고 폴오프를 끈 이동은 예전 키 끌기(끄는 동안 오브젝트가 따라옴), 그 밖은 v01.10 deform(미리보기 → 놓을 때 키에 씀).
- **[Perf] 놓을 때(키에 쓰기) 빨라짐** — 매 프레임 키 6,000 개 커브에서 986 → **240 ms**. refit 의 커브 평가가 구간마다 Python 루프였다 → 한 번에 계산(마야 골든 시험 그대로 통과).
  실제 씬(`CH_r_ArmIK_xx_ctl`, 6,000 프레임)에서 0.8 초 걸리던 것.
- 시험 `test_gizmo.py` 46항목(원근 카메라 고르기 · 화면 크기 · 축 · 평면 · 고리 각도 · 가중 회전 · Path 축, 컨텍스트 흐름, w/e 필터, 플러그인 그리기, 창). 전체 465/465.

## v01.08 (2026-11-20)

  - 키로 다시 맞출 때(refit) 허용 오차를 1/5 로 — 위치 오차의 2차 차분이 그대로 가속도 잡음이 된다. 그만큼 키가 더 들어갈 수 있다.
