# Changelog — A00420_Wrapper

## v01.01 (2026-08-10)
- **[Add] Swap — 선택한 가이드 쌍의 Source / Target 맞바꾸기** — 커브를 거꾸로(타깃 → 소스 순으로)
  골라 등록했을 때 지우고 다시 넣지 않아도 되도록, **선택한 행만** 소스/타깃을 맞바꾼다.
  - 이름뿐 아니라 **UUID 도 함께 바꿔** 리네임된 커브도 계속 따라간다.
  - 행의 성질인 **On / Flip 체크는 유지**하고, 이전 샘플링에서 계산해 둔 방향·시작점 정보(**Info** 칸)만
    더 이상 유효하지 않으므로 지운다.
  - 선택한 행이 없으면 아무것도 하지 않고 알린다(전체를 조용히 뒤집는 쪽이 더 위험하므로).

## v01.00 (2026-08-10)
첫 릴리스. 토폴로지가 다른 두 메시를 **커브 가이드**로 짝지어, 소스 메시를 타깃 메시 형태로 래핑하는
in-Maya PySide 툴. Wrap3D 의 `SelectPointPairs` + `Wrapping` 을 한 창에 넣고, 가이드를 낱개 포인트가
아니라 **커브 쌍**으로 바꾼 것이다.

- **[Add] Guide Pairs (커브 쌍 = 대응 포인트 다발)** — 소스 커브 1개와 타깃 커브 1개를 짝지어 두면 두
  커브를 **같은 개수로 호 길이 등간격 샘플링**해 i 번째 샘플끼리 대응시킨다. 커브 하나가 곧 수십 개의
  포인트 페어가 되므로, 입술·눈두덩·코 라인처럼 "선"으로 잡히는 특징을 훨씬 적은 손질로 맞춘다.
  - **Add Curve Pair** — 소스 커브 → 타깃 커브 순으로 선택(2·4·6… 개를 고르면 연속 쌍으로 한 번에 추가).
  - **Add Point Pair** — 입꼬리처럼 점 하나로 못 박고 싶은 곳은 버텍스/로케이터 쌍으로 추가.
  - **Curve from Edges** — 선택한 메시 엣지를 따라 가이드 커브를 만든다(`A00400_CurveTool` 재사용).
  - 행마다 **On**(사용 여부) / **Flip**(수동 방향 반전) 체크, **Info** 에 실제로 쓰인 샘플 수·방향·시작점 표시.
  - 노드는 **UUID 로 보관**해 커브를 리네임하거나 동명 노드가 있어도 목록이 깨지지 않는다.
- **[Add] 커브 방향 · 시작점 자동 정렬** — 커브 쌍에서 제일 자주 나는 사고 두 가지를 자동으로 잡는다.
  ① 두 커브의 진행 방향이 반대라 대응이 꼬이는 것, ② 닫힌 커브(눈·입 루프)는 방향이 같아도 **시작점(seam)**
  이 달라 통째로 돌아가는 것. 두 커브를 각자 중심/크기로 **정규화**한 뒤(메시 크기·위치가 달라도 비교 가능)
  정/역 × 시작점 N 가지 중 오차가 가장 작은 조합을 고른다.
- **[Add] Show Guide Links (대응 미리보기)** — 소스 샘플 i 와 타깃 샘플 i 를 잇는 선을 그려, 래핑 전에
  대응이 꼬였는지 눈으로 확인한다. 첫 샘플(시작점) 링크만 빨간색.
- **[Add] Wrap = TPS 워프 + 표면 투영 2 단계**
  - **1) Warp** — 컨트롤 포인트로 **Thin Plate Spline**(3D 커널 `phi(r)=r`)을 풀어 소스 메시 전체를 휜다.
    가이드가 있는 자리는 정확히 타깃 위로 가고, 사이는 휘는 에너지가 최소가 되게 부드럽게 채워진다.
    **Smoothness** 를 올리면 컨트롤 포인트를 정확히 통과하지 않는 대신 결과가 부드러워진다.
  - **2) Project** — 워프된 정점을 타깃 표면 최근접점으로 당긴다(비강체 ICP). 매 반복마다 **변위**를
    라플라시안으로 스무딩(**Relax**)해 표면에 붙이면서도 스파이크·뒤집힘이 안 생기게 한다.
    **Max distance** / **Normal angle limit** 로 엉뚱한 면(안쪽 구강 등)에 붙는 것을 막는다.
  - 워프만으로는 가이드 없는 영역(볼·이마)이 안 붙고, 투영만으로는 특징이 옆으로 끌려간다 → 두 단계가 짝.
- **[Add] Output** — **New mesh (duplicate)** 로 원본을 보존하거나 **In place** 로 소스를 직접 옮긴다.
  **Amount** 로 원본↔결과 블렌드. 쓰기는 `shape.pnts` **구간 setAttr** 이라 undo 가 정확하고
  히스토리·스킨이 걸린 메시에서도 동작한다(A00380_MeshTool 과 같은 방식).
- **[Add] 셸프 아이콘** — 가이드 커브 한 쌍 + 대응선(house style).

### 메모 (검증하며 확인한 것)
- `MMeshIntersector.create(node, matrix)` 에 **월드 행렬을 넘겨도** `getClosestPoint()` 결과는
  **오브젝트 공간**이다. 그래서 intersector 는 항등으로 만들고 좌표 변환은 numpy 로 한 번에 처리한다.
- 최근접점 20,000 회 기준 `MMeshIntersector` 0.6s vs `MFnMesh.getClosestPoint(kWorld)` 4.9s → 8 배.
- 컨트롤 포인트가 겹치면(커브 끝이 만나거나 가이드가 교차) TPS 행렬이 특이해져 결과가 폭발한다 →
  격자 반올림으로 겹친 점을 미리 합친다.
- 성능(mayapy 실측): 소스 32,222 정점 / 타깃 39,802 정점, 가이드 3 쌍, 투영 8 회 → **총 0.98 초**.
