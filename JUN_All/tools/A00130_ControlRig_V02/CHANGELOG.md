# Changelog — A00130_ControlRig_V02

`A00130_ControlRig`(V01)의 **템플릿 조인트 패러다임 재작성판**이다.
계획서: `JUN_All/docs/plans/A00130_ControlRig_V02_plan.md`

## v02.03 (2026-08-28)
**[Feature] Match 가 앞뒤로 **IK 편집 세션**을 연다 (계획서 Phase 4).**

`D01_IK_handle` 세트의 ikHandle 이 구동하는 조인트가 **매칭되지 않던 것**을 고쳤다
(사용자 보고). Match 는 이제 이 순서로 돈다:

```
IK 끄기  ->  매칭  ->  핸들 스냅 + 폴 벡터 역산  ->  IK 켜기
```

**진단 — 조용한 거짓 성공이었다**

IK 는 어트리뷰트 연결이 아니라 **솔버로** 쓴다. 그래서
`connectionInfo("jnt_mid.rotateZ", isDestination=True)` 가 **False** 이고
`channel_group_state` 도 `free` 로 본다. `matchTransform` 은 **성공하고**, 다음 평가에서
IK 가 도로 가져간다 — 로그에는 `[OK] matched` 가 찍히는데 씬은 그대로다.

`ikBlend` 를 껐다 켜는 것만으로도 부족하다. 되켜면 조인트가 **원위치**로 간다.
**핸들 스냅 + 폴 벡터 역산**까지 해야 편집이 남는다 —
`A00060_jointTool_V03` 의 IK Edit(`begin_edit`/`end_edit`/`cancel_edit`)을 **불러서** 쓴다.

**들어 있는 것** (`app/core/ik_session.py` 신규)
- `template_map.json` 의 `ik_handle_set` 으로 세트를 찾는다 — 조인트·세트·옵션 컨트롤러와
  **같은 이름 해석**(네임스페이스 먼저, 없으면 이름 그대로). 레퍼런스 케이지 지원.
- Match 탭 체크박스로 켜고 끈다 (기본 켬) + 세트/핸들 개수 표시
- 세트가 없으면 **조용히 세션 없이** 매칭한다(예전 동작)
- 핸들이 아닌 멤버는 무시하되 **몇 개인지 알린다**
- 매칭 중 예외가 나면 **체인을 시작 상태로 되돌리고** IK 를 켠 뒤 예외를 올린다 —
  반쯤 매칭된 체인에 IK 가 다시 붙는 것이 제일 나쁘다
- 지난 실행이 끊겨 **편집 모드에 남은 핸들**을 알아채서 표시한다

**`ikBlend` 는 이 리그에서 쓰이지 않는다** (사용자 확인). 그래서 계획서 7-4 가
"최대 기술 리스크" 로 꼽았던 **씬 전역 IK 정지**로 물러설 일이 없다 — 핸들별로 끈다.
다만 **가정하지 않고 확인한다**: `preflight()` 가 `ikBlend` 가 구동되는 핸들을 찾으면
**크게 알린다**(전제가 깨졌다는 뜻이고, 그대로 두면 씬 전체 IK 가 꺼진 채 매칭이 돈다).

**[Fix] `snapEnable` 을 세션 동안 꺼 둔다 — 그래야 undo 가 정확히 복원된다.**

`snapEnable` 이 켜져 있으면 **마야가 평가 중에 ikHandle 의 translate 를 직접 쓴다.**
그 쓰기가 편집 사이사이에 끼어들어 undo 큐가 재구성하지 못한다 (실측):

```
snapEnable 그대로    before=[20,0,0]  after=[18,0,3]  undo=[19.063, 4.226, 0]   X
snapEnable 껐다 켜기  before=[20,0,0]  after=[18,0,3]  undo=[20, 0, 0]           O
```

끄고 있어도 `end_edit` 은 `xform` 으로 **명시적으로** 스냅하므로 결과는 같다.
되켜는 것은 스냅이 끝난 **뒤**다.

**검증**(mayapy headless, **IK 44 + Match 110 + Length 126 = 280항목 전부 통과**):
**세션 없이 매칭하면 조인트가 안 남는 것**(증상 재현) · **세션을 걸면 남는 것** ·
로그가 `ON -> 매칭 -> OFF` 순인가 · 종료 후 `ikBlend` 복원 · 씬 전역 IK 가 안 꺼졌는가 ·
편집 상태가 안 남았는가 · 핸들이 새 체인 끝을 따라가는가 · **네임스페이스 케이지** ·
세트가 없을 때 · 핸들 아닌 멤버 · **`ikBlend` 구동 시 경고** ·
**예외 시 되돌리고 IK 복원** · 남은 편집 상태 감지 · **undo 한 스텝** · UI 경로.

## v02.02 (2026-08-28)
**[Fix] Match — 막힌 채널을 **그룹 단위**로 가른다. 일부만 막혀도 나머지는 매칭한다.**

`A01_Arm_L_01_UpperArm` 처럼 **`pointConstraint` 가 걸린 오브젝트**는 위치가 리그에
묶여 매칭이 안 되는데, 그때 **회전까지 매칭 안 된 채 방치**됐다(사용자 보고).
채널 하나라도 막히면 **그 오브젝트를 통째로 건너뛰었기** 때문이다.

**실측 — 컨스트레인트는 그룹을 통째로 막는다**

| 걸린 것 | translate | rotate | 지금 하는 일 |
|---|---|---|---|
| `pointConstraint` | 3/3 | 0/3 | **회전만 매칭** |
| `orientConstraint` · `aimConstraint` | 0/3 | 3/3 | **위치만 매칭** |
| `parentConstraint` | 3/3 | 3/3 | 통째로 건너뛴다 |
| `translateX` 만 잠금 | 1/3 | 0/3 | 위치는 손대지 않고 회전만 + 경고 |

→ **그룹(translate / rotate) 단위 all-or-nothing.**

- **그룹이 통째로 막혔으면** 그 그룹만 건너뛰고 나머지는 매칭한다 —
  `matched rotation only - position is driven by the rig`.
- **축이 일부만 막혔으면 그 그룹은 건드리지 않는다.** `translateX` 만 잠근 채 위치를
  맞추면 `t = [90, 2, 3]` 처럼 **반쪽**이 된다(실측). 크게 경고한다.
- **양쪽 다 막혔으면** 건너뛰고 이유를 적는다.

무엇을 넣고 무엇을 뺐는지 **오브젝트마다 적고**, 마지막에 부분 매칭 수와
반쪽 그룹 수를 요약한다. `apply()` 결과에 `partial` · `driven_t` · `driven_r` · `half` 추가.

**[Refactor]** `scene_utils.channel_group_state(node, group)` 신설 —
`free` / `driven`(전부 막힘) / `partial`(일부만 막힘) 을 가른다.

> 원래 규칙("반쯤 옮겨진 상태가 제일 나쁘다 - 통째로 건너뛴다")은 **틀리지 않았지만
> 범위가 과했다.** 반쪽이 나쁜 것은 **그룹 안에서** 갈릴 때지, translate 와 rotate
> 사이에서가 아니다. 컨스트레인트가 그룹을 통째로 막는다는 것을 재고 나서 갈렸다.

**검증**(mayapy headless, **Match 110 + Length 126 = 236항목 전부 통과**):
`pointConstraint` 에서 **회전이 매칭되는가**(예전에는 건너뛰었다) ·
`orientConstraint` 에서 위치가 매칭되는가 · `parentConstraint` 는 통째로 건너뛰는가 ·
**축 하나만 잠기면 그 그룹을 손대지 않고 경고하는가** · 위치 전용 세트에서 회전
컨스트레인트가 방해되지 않는가 · `channel_group_state` 단위 판정.

## v02.01 (2026-08-28)
**[Feature] `Length` 단계 — 템플릿 조인트 사이 거리를 옵션 컨트롤러에 쓴다.**

V01(`rig_matcher.py:255` 외 3곳)이 **아바타 본**을 재서 옵션 컨트롤러 어트리뷰트에
넣던 것을, **템플릿 조인트**를 재는 것으로 옮겼다. 값은 같고 **아바타의 조인트 이름에
의존하지 않게 된다.** 짝은 손으로 담는 TSL 대신 `length_map.json` 이 갖는다.

**어트리뷰트 12개 — 하나도 빼지 않는다**

부위(팔 좌우·다리 좌우)마다 세 개씩이다. `_up`/`_low` 는 `total` 만큼 필수다.
`Arm_L` ↔ **`Arm_r`** 처럼 좌우 표기가 깨져 있어(대문자 vs 소문자)
**대칭으로 유도하지 않고 json 에 전부 적었다** — 유도하면 한쪽이 조용히 틀린다.
V01 툴과 아카이브(`01_Modules` · `03_Modules_Test`) 전 버전을 훑어 **12개가 전부이고
그 밖에 없다**는 것을 확인했다.

**들어 있는 것**
- `Length` 탭 — `Measure`(씬 불변) → 표로 값 확인 → `Write Values`(undo 한 스텝)
- `Total` 콤보 — `straight`(V01 과 동일, 기본) / `sum`(완전히 폈을 때)
- 옵션 컨트롤러를 **3단계로** 찾는다 — 수동 지정 > 정확한 이름 > 이름 부분 매칭.
  **후보가 여럿이면 고르지 않고 멈춘다**(V01 은 첫 개를 골랐다).
- **`Get Selected` / `Auto` 버튼 + 이름 필드** — 자동으로 못 찾아도 손으로 지정할 수 있다.
  셰이프를 골라도 트랜스폼으로 올려 준다. 리그 이름 규칙은 프로젝트마다 다르므로
  **자동은 편의, 수동이 보장이다.**
- 씬 선형 단위 표시 (`Measured in cm`)

**실측으로 갈린 설계**
- **`total` 은 `up + low` 가 아니라 직선 거리다.** 30° 굽으면 **3.4 % 짧다**.
  IK 스트레치 기준이면 보통 합이 맞지만 **조용히 바꾸지 않고** 기본값은 V01 그대로 두고
  **두 값의 차이를 표에 드러내** 고르게 했다.
- **`min`/`max` 는 자르지 않고 예외를 낸다.** 그래서 범위 밖이면 **잘라 쓰지 않고 거부**한다 —
  잘린 길이는 틀린 리그를 조용히 만든다.
- **거리는 씬 선형 단위를 탄다** (같은 두 점이 cm 10 · m 0.1 · mm 100).
  단위를 **바꾸지 않고 표시만** 한다.
- **`cmds.ls("*토큰*")` 은 네임스페이스를 넘지 않는다.** 노드가 `CAGE:...` 면 **빈 목록**이
  온다 — `recursive=True` 라야 한다. 게다가 **셰이프까지 잡아**(컨트롤러는 커브다)
  후보가 2개로 보인다 — `type="transform"` 이 필요하다.
  이 둘이 겹쳐 옵션 컨트롤러를 못 찾았다.
- **V01 의 `TKN_OPTION_CTL` 은 전체 이름이 아니라 토큰이었다.** 실제 이름은
  `CH_n_OptionAll_xx_ctl` 이고 V01 은 `in` 으로 부분 매칭했다. **상수를 옮길 때는
  그 상수가 어떻게 쓰이는지 함께 옮겨야 한다.**
- **없는 어트리뷰트에 `setAttr` 은 `RuntimeError` 를 낸다.** V01 은 그 자리를 감싸지 않아
  **Match 전체가 멈췄다.** 여기서는 쓰기 전에 존재·잠금·연결·범위를 **전부 미리 보고**
  막힌 것만 건너뛴다.

**부위를 더하려면** `length_map.json` 에 줄을 더한다 — **코드는 안 고친다.**
스파인·손가락은 V01 에도 측정이 없어 넣지 않았다.

**[Refactor]** `scene_utils._plug_writable` → **`plug_writable`** 공개.
Match(트랜스폼 채널)와 Length(옵션 컨트롤러) 두 곳이 쓰므로 내부 헬퍼가 아니다.

**검증**(mayapy headless, **Length 126 + Match 88 = 214항목 전부 통과**):
**12개가 하나도 안 빠지고 실리는지 개수로 센다** · 굽은 체인에서 직선≠합과 표식 ·
`sum` 모드 · **케이지를 임포트/레퍼런스한 두 경우** · 어트리뷰트 하나가 없어도
**나머지 11개가 써지는가**(V01 은 여기서 멈췄다) · 잠김/연결/범위 밖을 건너뛰는가 ·
**범위 밖을 자르지 않는가** · **네임스페이스를 넘는 토큰 검색** · **셰이프가 후보를 부풀리지 않는가** ·
후보가 둘이면 멈추는가 · **수동 지정이 이기는가** · `Get Selected` 가 셰이프를 트랜스폼으로
올리는가 · 전부 0 이면 경고하는가 ·
단위 변경 · `Measure` 가 씬을 안 바꾸는가 · **undo 한 스텝** · UI 버튼 경로.
**변이 테스트로 검증을 검증했다** — `length_map.json` 에서 `_up`/`_low` 8개를 빼면
**27항목**이, `option_ctl` 을 옛 토큰으로 되돌리면 **3항목**이 실패한다.

## v02.00 (2026-08-28)
**[Feature] 신규 — Phase 1 (최소 기능 : Match).**

컨트롤러(cage) 세팅의 "사람이 판단하는 자리" 를 **템플릿 조인트**로 옮긴다.
사람은 조인트를 눈으로 놓고, 나머지는 버튼이 한다.

**들어 있는 것**

- **`Create Template Joints`** — 매핑 표의 이름·부모 관계대로 조인트 생성(전부 원점).
  배치는 사람 몫이다. 이미 있는 조인트는 안 건드린다(멱등).
- **`Check`** — 없는 템플릿 조인트 / 없는 케이지 세트를 보고. **씬 불변.**
- **`Match`** — 각 케이지 세트의 원소를 짝인 조인트 자리로. **undo 한 스텝.**
- **`Cage namespace` 콤보** — 씬의 네임스페이스에서 고른다(규칙으로 정하지 않는다).

**데이터는 json 이다** — `app/data/mapping/v001/template_map.json`.
조인트 **80** · 짝 **74** · 매칭 대상 없는 구조용 조인트 **10** · 위치 전용 세트 **6**.
짝이 늘거나 줄면 이 파일만 고치면 되고, 케이지 버전이 갈리면 폴더를 늘리면 콤보에 뜬다.

**설계에서 짚은 것**

- **값이 언제나 목록이다.** 원본 표에서 한 조인트가 세트 둘을 갖는 모양이 두 가지였다 —
  `helper_foot_l` 은 한 줄에 둘, **`helper_ball_l` 은 줄이 둘로 나뉘어** 있었다.
  `{조인트: 세트}` 로 만들면 **한쪽이 조용히 사라진다.**
- **하위 세트는 통째로 무시**하고 재귀하지 않는다. 몇 개를 무시했는지 알린다.
- **없는 짝은 로그만 남기고 계속 간다** — 한 짝이 없다고 전체가 멈추지 않는다.
- **잠기거나 구동되는 오브젝트는 반쯤 옮기지 않는다.** `matchTransform` 은 **잠긴 채널을
  조용히 건너뛴다**(실측: `translateX` 만 잠근 오브젝트가 X 만 안 움직이고 에러도 없었다).
  그래서 미리 잠금·입력 연결을 보고 막혀 있으면 **그 오브젝트를 통째로 건너뛴다.**
- **이름은 정해 두지 않고 찾아본다** — `Cage namespace` 를 고르면 조인트든 세트든
  `CAGE:helper_pelvis` 를 먼저 보고, 없으면 `helper_pelvis` 를 본다. 그래서 케이지를
  **레퍼런스**해도, **임포트**해도, 조인트만 로컬로 만들어 둬도 전부 된다.
  둘 다 있으면 `ambiguous ...` 로, 못 찾으면 `looked for CAGE:x and x` 로 **알린다**.
  `Create Template Joints` 도 같은 판정을 써서 **레퍼런스가 이미 준 조인트를 하나 더
  만들지 않는다.**

  > 처음에는 "템플릿 조인트는 로컬, 세트만 레퍼런스" 로 보고 **세트에만** 붙였다.
  > 실제 케이지 파일에는 **조인트도 같이 들어 있어서** 레퍼런스하면 `Check` 가 전부
  > `joint missing` 이 됐다(임포트는 멀쩡했다). 사용자가 그 증상을 보고했고 mayapy 로
  > 재현해 고쳤다. **이름 해석은 정하지 말고 찾아보는 편이 맞다.**

**V01 에서 가져오지 않은 것**: `MayaScene.match_transforms` 는 팔로워의 `rotateOrder` 를
