# `worklog/` — 지난 달 작업 일지 보관

루트 [`WORKLOG.md`](../WORKLOG.md) 가 **현재 월**을 담고, 이 폴더가 **지난 달**을 담는다.

**루트 `JUN_All/docs/WORKLOG.md` 는 절대 옮기거나 이름을 바꾸지 않는다.**
이 경로를 가리키는 곳이 저장소 안에 **60군데**(메모리 · 툴 문서 · 계획서)다.
파일만 제자리에 두면 분할해도 링크가 하나도 안 깨진다. 자라는 부분만 조용히 이쪽으로 내린다.

---

## 왜 월 단위인가

같은 문제를 `JUN_Study` 의 `UPDATELOG.md` 도 겪었는데, **거기서는 연도 단위로 정하고 월별을 기각했다.**
WORKLOG 은 반대다. **기제는 같고 눈금만 다르다.** 이유는 밀도다.

| | `JUN_Study/UPDATELOG.md` | **이 문서 (`WORKLOG.md`)** |
|---|---|---|
| 성격 | 한 줄 색인 | **하루치 서술** |
| 블록당 | 3줄 / 372 B | **110줄 / 11.6 KB** |
| 2.4개월 실측 | 181줄 / 17.6 KB | **4,742줄 / 497 KB** |
| 연 환산 | ~360줄 / 45 KB | **~24,000줄 / 2.5 MB** |
| 루트가 담는 단위 | **연도** | **월** |

**연도 단위로 자르면 1년치가 24,000줄 / 2.5MB 다.** 아카이브했다고 말할 수 없는 크기라 눈금을 한 칸 내렸다.

`UPDATELOG` 에서 월별을 기각했던 근거 셋이 여기서는 셋 다 뒤집힌다.

| 기각 근거 | 여기서는 |
|---|---|
| "5년에 파일 60개인데 여는 건 1~2개" | **한 달이 2,000줄이라 60개가 오히려 적정 단위** |
| "훑기가 깨진다" | **훑는 문서가 아니다.** "그때 그 툴 왜 그렇게 고쳤지"를 **검색**하는 문서라 파일이 갈려도 grep · Obsidian 검색은 그대로다 |
| "충돌이 안 줄어든다" | **수동 갱신**이라 충돌 논점이 크지 않다 |

### 진짜 이유는 길이가 아니라 컨텍스트

분할 직전 `WORKLOG.md` 는 **308,724자 ≈ 15만~24만 토큰**이었다.
스크롤이 귀찮은 수준이 아니라 **세션에서 통째로 열 수 없는 크기**다.

솔직히 말하면 **분할해도 이 문제가 완전히 풀리지는 않는다.** 한 달치도 2,000줄이 넘는다.
분할이 주는 것은 "전체를 읽는다"가 아니라 **"최근 것만 읽는다"가 가능해지는 것**이고,
그래서 **루트는 작을수록 좋다.** 최신이 위에 쌓이는 `prepend` 구조라 앞부분만 읽어도 최근 며칠이 나온다.

## 파일명

```
YYYY-MM.md        예) 2026-06.md, 2026-07.md
```

- **ISO 형식.** 본문 헤딩이 `## 2026-08-25` 이므로 같은 표기를 쓴다.
- 루트 `WORKLOG.md` 와 **같은 포맷**(`## YYYY-MM-DD` + `> [!summary]` 콜아웃)을 그대로 유지한다.
  내려온 뒤에도 읽는 법이 달라지지 않아야 한다.

---

## 언제 내리나 — 트리거

**월이 바뀌면 내린다. 그게 전부다.**

새 달의 첫 항목을 쓸 때, **직전 달을 통째로** `worklog/YYYY-MM.md` 로 옮긴다.

> 줄 수 기준 트리거를 따로 두지 않는 이유: 하루 110줄 페이스에서는
> **월 경계가 어떤 크기 기준보다 항상 먼저 온다.** 조건을 하나로 줄이는 편이 안 잊는다.

---

## 어떻게 내리나 — 절차

1. 루트 `WORKLOG.md` 에서 **그 달의 `## YYYY-MM-DD` 블록 전부**를 잘라 `worklog/YYYY-MM.md` 로 옮긴다.
   **본문은 한 글자도 고치지 않는다.** 순수 이동이다.
2. 새 파일 머리에 frontmatter + 제목 + 루트로 돌아가는 링크 + 기간·작업일수를 붙인다 (기존 파일 참고).
   **★ 상대 경로를 한 단계 올린다** — 일지 항목은 `[A00170_driverTool](A00170_driverTool.md)` 처럼
   같은 폴더의 툴 문서를 가리킨다. 한 단계 깊어졌으므로 **`../` 를 붙여야** 한다.
   본문 텍스트는 그대로 두되 **링크 경로만** 고친다. 2026-08 첫 롤링에서 **50건**이 여기 걸렸다.
3. 루트 `WORKLOG.md` 의 **`## 지난 달 보관` 표에 한 줄** 등록한다.
4. **이 README 아래 표에도 한 줄** 등록한다.
5. **한 커밋**으로 올린다. 커밋 스코프는 `docs(worklog)`.
6. 옮긴 뒤 **날짜 개수와 본문 줄이 보존됐는지 확인한다** (아래 검증 명령).

**하지 않는 것**

- 루트 `WORKLOG.md` 를 옮기거나 이름을 바꾸는 것 (60군데가 이 경로를 가리킨다)
- 내리면서 요약·압축하는 것 (별도 결정이고, 이동과 섞으면 무엇이 바뀌었는지 못 본다)
- 빈 달 파일을 미리 만들어 두는 것
