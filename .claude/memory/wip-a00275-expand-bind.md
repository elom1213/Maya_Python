A00275_skinTool_V01 **Expand Bind 탭** (v01.08→**01.09**, 2026-08-12). 입술·눈 같은 **원형 엣지
루프** 위 조인트들에 바인드할 때 조인트 사이 웨이트를 고르게 까는 기능. Kangaroo
`SkinCluster > ClosestExpand` 대체.

**Kangaroo 가 고르지 않은 이유**(`kangarooTabTools/weights.py` 의 `bindToClosestVertexAndExpand`):
조인트 사이 경로를 **토폴로지 등간격**(`fT = (p+1)/(len(iPath)-1)`)으로 섞고 바깥은 **루프 개수**로
b-spline 감쇠 → **실제 엣지 길이를 안 본다**. 간격이 조금만 불규칙하면 쏠린다.

**우리 방식**: 조인트별 최근접 버텍스(seed) → **엣지 길이 누적 측지 거리**(Dijkstra, 저장 집합 안으로
제한) → `거리/반경` 을 falloff 커브에 → **버텍스마다 조인트 사이 정규화**. 선형 커브면 정확히
`d2/(d1+d2)`. 탐색을 집합 안으로 가두므로 윗입술 falloff 가 아랫입술로 새지 않는다.

**엣지 루프 입력 (v01.10) — 여러 줄짜리 밴드에는 사실상 필수**

루프 없이 영역 전체를 한 거리로 재면, 루프에서 멀어질수록 **바깥으로 나간 거리가 반경을 잡아먹어
먼 조인트의 falloff 가 먼저 0** 이 된다 → 비율이 딱딱하게 갈라진다(11x7 격자 실측):

```
루프 줄                 1.0  0.9  0.8  0.7  0.6  0.5
루프+3 줄 (루프 없이)   1.0  1.0  1.0  1.0  0.75 0.5   <- 뭉개짐
루프+3 줄 (루프 입력)   1.0  0.9  0.8  0.7  0.6  0.5
```

해결: 루프 전체를 시작점으로 하는 **다중 소스 Dijkstra 한 번**으로 (루프에서 떨어진 거리 + 가장 가까운
루프 버텍스 anchor) 를 얻고, **조인트 비율은 anchor 의 루프 호 거리로만** 낸다. 루프 바깥 방향은
`Across width` 로 **amount 만** 줄인다(비율 불변). 닫힌 루프는 감아 도는 짧은 쪽으로 잰다.
`Fit to Joints` 도 루프가 있으면 루프 위 간격으로 측정.

**설계에서 놓치기 쉬운 것**

- **정규화만 하면 커브가 무의미해진다** — 반경 끝에서 1 → 0 으로 뚝 끊긴다(단일 조인트면 전 구간 1.0).
  그래서 `coverage = min(1, 조인트별 커브값 합)` 을 곱한다. 조인트 **사이**는 합이 1 이라 coverage 도 1
  (분배만 일어남), 바깥으로만 페이드. 이 덕분에 Blend 의 **최댓값이 정확히 Blend** 가 된다.
- **Blend** 는 `Blend × coverage`. 단, 대상 외 인플루언스가 **없는** 버텍스는 남길 곳이 없어 무조건 1
  (합이 1 이 아니면 마야가 어차피 재정규화한다).
- 거리는 세 모드 모두 **조인트 위치가 아니라 seed 버텍스에서** 잰다(조인트가 표면에서 떠 있어도 자기
  버텍스는 1 로 시작).
- 커브 값이 0 인 정점(반경 끝)은 **손대지 않는다** — 0 을 쓰면 기존 웨이트를 지우는 셈이 된다.

**UI**: 버텍스 집합은 **리스트 위젯으로 만들지 않는다**(수천 개 → 창이 느려짐, 사용자 요청). 요약 라벨 +
Select/Clear, 재선택은 연속 id 를 `vtx[a:b]` 로 압축. 조인트는 공용 TSL.
falloff 커브 편집 위젯을 새로 만들었다(`app/ui/falloff_curve_widget.py`) — 마야
`gradientControlNoAttr` 는 **cmds 전용이라 PySide 창에 못 쓴다**. 계산/그리기가 같은 함수
(`app/core/falloff.py`)를 쓴다. 다른 툴에도 쓸 일이 생기면 Framework 로 올릴 후보.

성능: 순수 파이썬 Dijkstra 로 25,921 버텍스 / 조인트 20개 **0.60s** — numpy 불필요.
검증 코어 44 + UI 28 항목([[mayapy-headless-verify]]). 토러스 테스트 시 주의: 정점 id 는 **minor 링
단위**로 묶여 있어 `id 산술`로 major 루프를 고르면 끊긴 링이 나온다(좌표로 골라야 함).
